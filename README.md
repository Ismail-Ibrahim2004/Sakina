# 🌙 سَكِينَة | Sakina

تطبيق **سَكِينَة** هو رفيقك اليومي لكل مسلم، يجمع بين البساطة، والروحانية، والتصميم العصري المريح للعين (بألوان الكحلي الداكن والذهبي). تم تصميم التطبيق لمساعدتك في قراءة القرآن الكريم، ومتابعة أوقات الصلاة بدقة، والمداومة على الأذكار.

![Sakina App](assets/images/Splash_logo.png)

## ✨ المميزات الرئيسية (Features)

* **📖 القرآن الكريم:**
  * قراءة القرآن الكريم كاملًا بخط واضح ومريح للعين.
  * حفظ تلقائي لآخر صفحة أو سورة قمت بقرائتها للعودة إليها بسهولة.
  * تصميم يعتمد على الـ (Custom Scaffold) بنقوش إسلامية مريحة.

* **🕌 مواقيت الصلاة (Prayer Times):**
  * حساب أوقات الصلاة بدقة بناءً على موقعك الجغرافي.
  * عداد تنازلي لمعرفة الوقت المتبقي على الصلاة القادمة.
  * تسليط الضوء على الصلاة الحالية والصلاة القادمة.

* **📿 الأذكار والمسبحة (Azkar & Tasbih):**
  * قسم خاص لأذكار الصباح والمساء.
  * مسبحة إلكترونية (Zikr Counter) للمداومة على التسبيح بسهولة.

* **✨ تجربة مستخدم فريدة (UI/UX):**
  * شاشة ترحيب (Onboarding) جذابة ومميزة تظهر عند أول استخدام للتطبيق.
  * دعم كامل للوضع المظلم بلمسات ذهبية (Dark Navy & Gold).
  * شريط تنقل سفلي (Bottom Navigation) سلس وسريع للانتقال بين أقسام التطبيق.

## 🛠️ التقنيات والمكتبات المستخدمة (Tech Stack)

تم بناء التطبيق باستخدام إطار عمل **Flutter**، ويعتمد على مجموعة من أفضل المكتبات:
* `provider` : لإدارة حالة التطبيق (State Management).
* `shared_preferences` : لحفظ البيانات المحلية مثل حالة الـ Onboarding وآخر صفحة مقروءة في القرآن.
* `qcf_quran` : لعرض نصوص القرآن الكريم.
* `adhan` : لحساب مواقيت الصلاة بدقة.
* `geolocator` : لتحديد موقع المستخدم لحساب مواقيت الصلاة.
* `hijri` : لعرض التاريخ الهجري.
* `smooth_page_indicator` : لعرض مؤشر صفحات الـ Onboarding بشكل احترافي.
* `flutter_screenutil` : لضمان توافق التصميم مع جميع أحجام الشاشات.

## 🚀 كيفية تشغيل التطبيق (Getting Started)

1. قم بعمل استنساخ (Clone) للمستودع:
```bash
git clone https://github.com/Ismail-Ibrahim2004/Sakina.git
```
2. قم بتثبيت الحزم والمكتبات:
```bash
flutter pub get
```
3. قم بتشغيل التطبيق على محاكي أو جهاز حقيقي:
```bash
flutter run
```
